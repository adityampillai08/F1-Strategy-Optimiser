# Mathematical telemetry upgrade

The workspace charts are populated from the `/api/optimize` response generated by the GNU Octave engine:
- lap-time telemetry uses the selected optimized strategy's simulated lap times, with fixed pit-loss removed for the underlying pace trend;
- fuel-load telemetry uses `fuelLoads` returned by `simulate_strategy`;
- tyre-age telemetry uses `tyreAges` returned by `simulate_strategy`;
- tyre-degradation curves use the actual `baseTime`, `degradationA`, and `degradationB` coefficients returned by the engine and evaluate the model formula for Soft, Medium, and Hard compounds;
- the parameter strip exposes those coefficients and the fuel coefficient for transparency.

These are educational model outputs, not official F1 telemetry. The Race Simulation page remains a separate visual field simulation and is not claimed to be a driver-by-driver execution of the optimizer output.


## Three-stop strategy support

The optimizer now considers one-, two-, and three-stop strategies. A three-stop plan contains four stints and must respect the minimum stint length. The browser API enables deterministic coarse-to-fine search to keep longer races responsive; therefore the browser results are an efficient search, not an exhaustive proof over every possible pit-lap combination. The displayed winner is the fastest candidate evaluated by the configured model.
